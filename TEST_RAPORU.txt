FOTONMAP Hat Seçici v0.4.1 - AUDIT RAPORU

Kaynak proje:
Foton-Hat-main.zip

- Accessibility servisi manifestte yok.
- Eski Accessibility kaynak kodu temizlendi.
- Eski DXF tablet parser'ı temizlendi.

- Yeni seçim eski pending seçimi temizliyor.
- Geri çıkış yarım seçim isteğini iptal ediyor.

- Pinch zoom, double tap zoom, +, -, SIĞDIR mevcut.
- GitHub workflow Android 34 / Java 17 / Gradle 8.7 ile uyumlu ayarlı.
